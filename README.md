# Gymletics – Gym Website

A clean, responsive multi-page website for a fictional gym. Built with plain HTML, CSS and JavaScript – no frameworks, no build step.

## Pages

| Page | Content |
|------|---------|
| `index.html` | Home – hero, reasons to join, page teasers, reviews preview |
| `about.html` | Why Gymletics – six reasons, facility, coaching team |
| `classes.html` | Class categories and an interactive weekly schedule (filter by day and category) |
| `reviews.html` | Overall rating, review summary and member reviews |
| `join.html` | Membership plans, newsletter signup (20% off the first 6 months) and FAQ |
| `checkout.html` | Checkout – plan selection, discount code, live order summary and confirmation |

## Run locally

Open `index.html` in your browser – that's it.

## Notes

- Demo project: the gym, address and reviews are fictional.
- The newsletter form is front-end only and does not send any data.
- Photos from [Unsplash](https://unsplash.com).
